# 性能回归

更新：2026-09-17。身份与目标已合入 [当前规则](07-当前游戏规则.md)，原迭代说明见 [档案](archive/21-性能回归与玩家身份迭代.md)。

## 已实现

单格建造只更新变化地块；远景按材质合批；静态阴影按需刷新；住宅状态按模拟步更新；传播路径开启时才合并生成；拾取只查地面和建筑主体。本地性能版退出演练直接恢复原模型的颜色、缩放和状态；仅真正改建或切换地图时重建。标准 DPR 上限 1.5；流畅模式上限 1 并关闭阴影。

河海共用一张持久网格、64×64 噪声纹理及时间参数；无额外深度/反射通道。岸距近似深度不能为任意入水物体自动生成交界泡沫。

## 09-17：八关版性能修复（本地）

用户反馈持续卡顿及镜头不顺。定位到镜头旋转也调用 `setPixelRatio`/`setSize`，即使尺寸未变仍重置画布；现在仅实际窗口尺寸/DPR改变时调整缓冲。另合并整片固定岩地、各栋房屋装饰及火焰，保留独立受热主体；同格悬停复用预览，喷淋状态仅在模拟步更新，隐藏页面不继续渲染。

1280×720、DPR 1、标准画质，旧第 8 关同一住宅与双喷淋布局，各 600 帧：

| 样本 | 绘制调用 | 三角形 | CPU P95 | FPS |
| --- | ---: | ---: | ---: | ---: |
| [优化前](evidence/campaign-perf-before-build.json)，生产预览 | 296 | 10510 | 5.1ms | 32 |
| [合批后](evidence/campaign-perf-after-build.json)，开发服务 | 84 | 10510 | 2.5ms | 32 |

三角形数量未变，绘制调用下降约 72%，CPU P95 下降约 51%。样本来自同一内置浏览器；旧版为生产构建、新版为开发服务，且此表在后续地图重校前采集。帧率未提高，不能宣称真机卡顿已经解决；需用户设备复测 GPU/高 DPI 情况。另有[旧版演练数据](evidence/campaign-perf-before-run.json)，不与不同新地图混比。

本轮水压规则 CPU 基准：60 次旧场景 P95 6.26ms，64 次八关 P95 7.37ms，均通过 100ms 退化门槛。

新增结构回归约束可见棋盘 <100 次提交、240 次相机更新不触发缓冲重置、同格 120 次悬停不新建预览、重试保留所有未变模型。

## 历史实测证据

以下均为内置浏览器 1280×720、DPR 1，规划阶段 600 帧。CPU 为 RAF 回调耗时，不是 GPU 时间。

| 样本 | 布局 / 版本 | 绘制调用 | CPU P95 | FPS |
| --- | --- | ---: | ---: | ---: |
| [早期优化前](evidence/performance-before.json) | 默认，无水景 | 810 | 8.8ms | 32 |
| [早期优化后](evidence/performance-after.json) | 同上 | 345 | 5.5ms | 32 |
| [水景初稿](evidence/water-blend-performance.json) | 双喷淋，程序噪声 | 350 | 13ms | 32 |
| [当前水景](evidence/water-blend-texture-performance.json) | 双喷淋，纹理噪声 | 350 | 10.3ms | 31.9 |

前两行和后两行分别比较，不能把不同版本/布局当同条件基准。帧率未明显提升，约 32 FPS 的原因仍待独立浏览器/设备定位。水景采样包含初始化长帧，不应把少量标题样本作为稳态数据。

[五次单格建造](evidence/performance-after-edits.json)耗时 0.7–1.6ms；一次退出演练整体恢复约 31ms。旧版最大布局耗时混有初始化，不能直接比较单次编辑。

## 自动回归

`npm run test:perf` 包含 9 项结构检查：未改地块保留、替换几何释放、退出模拟无重建恢复、远景≤24 批、长帧统计、水景 600 次更新保持一张网格等断言（部分在同一测试中）。

八关版新增地面威胁/飞火反馈的固定缓冲检查：连续三次完整演练保持两件渲染对象和同一顶点/颜色缓冲，无逐帧几何重建。

CPU 基准预热 9 次，再运行 60 次完整 450 步模拟，断言 0/6/12 户结果。P95 默认上限 100ms，可用 `PERF_SIM_BUDGET_MS` 调整；这是严重退化门槛，不是 60 FPS 承诺。水景修订时本机 P95 3.14ms、最大 5.22ms（历史）。本轮 Node 24.19 样本：旧场景 60 次 P95 6.17ms、最大 10.8ms；新增八关 64 次完整模拟（含风向、飞火与覆盖）P95 7.85ms、最大 9.5ms，同样断言不超过 100ms。本轮未新增浏览器 FPS 样本，不与历史 FPS 混比。

## 浏览器回归

1. 生产预览 URL 加 `?perf=1`，固定尺寸、DPR、标准画质和布局；采集各主要阶段 600 帧并保存可见 JSON。
2. 检查连续建造/撤销、重试恢复、路径开关、镜头变换和流畅模式；避免不同场景/画质混用同一组样本。
3. 比较帧间隔 P95、慢帧数、CPU P95、绘制调用和几何体数量。同设备同布局 CPU P95 增长超过 25% 或规划调用超过 400 时调查。
4. 独立浏览器/目标设备继续验证 GPU 与实际卡顿。自动结构测试和 Node 基准都不能替代此步骤。
