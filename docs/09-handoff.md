# 当前接续点

用户已明确继续《火线街区》。最新 [后续目标与优先级](11-next-milestones.md)为待评估计划，建议先做单地图 v0.2；不应继续开发或重新选择此前的新原型候选。

最新补充：[玩家吸引力工作项](12-player-appeal-workitems.md)要求把题材、开始界面、基础建造手感、完整单局与结算一起纳入首版计划。林缘小镇是待评估题材；不要将其当作用户已确认的设定。

## 现在可以做什么

1. 克隆仓库，使用 Node 24.13.1，执行 `npm ci`、`npm test` 和 `npm run dev`。
2. 直接运行默认街区，再做一次布局调整，理解当前规则。
3. 阅读 `docs/07-rules.md`，把真实体验反馈记录在 `docs/04-devlog.md`。

## 当前版本的关键判断

- 核心闭环已可玩，规则和浏览器结果一致。
- 已有连续防火带和消防覆盖两种达标策略。
- 防火带完整隔离的解较容易找到；目前更接近教学关，不能宣称平衡完成。
- 火灾模拟是玩法抽象，所有数值集中在 `src/sim/model.ts`。
- `docs/01-brief-and-plan.md` 保留原始提案，实际行为以规则文档和代码为准。

## 建议下一轮优先级（具体范围待用户评估）

1. 先明确题材与建设动机、四个关键画面和完整单局流程；具体题材供用户评估。
2. 在一张图里同步修复等待、局部改善和设施取舍，并加入开始、建造手感、危机反馈、结算与重试，提交 v0.2 给用户及首次玩家体验。
3. 根据真实试玩决定后续两关或三关、建造便利功能与视听投入；消防设施提前降温的规则需要被正确理解。
4. 提交前处理评审访问与正式 Pages 链接，并完成公网与设备验收。部署准备可提前做，公开动作按授权执行。

## 代码导航

- `src/sim/model.ts`：地图、建造、预算、确定性模拟与事件。
- `src/sim/model.test.ts`：16 项规则与场景检查。
- `src/view.ts`：Three.js 场景、坐标、拾取、建筑状态与传播可视化。
- `src/main.ts`：界面、阶段状态、暂停与重试、存档与复盘。
- `src/style.css`：桌面布局、窄屏样式和减少动态效果支持。
- `docs/deployment/pages.yml`：尚未启用的部署模板。

## 同步约定

正式接续前先执行 `git status` 和 `git pull --ff-only`。跨设备共享代码和文档，不共享浏览器 localStorage 或本任务的完整聊天上下文。更新文档摘要即可保留设计决策与验证证据。
