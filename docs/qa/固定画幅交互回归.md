- 历史版本有 17 项规则检查和生产子路径浏览器记录；这些是历史证据，不自动继承为本轮通过。

- 独立 QA 在主控交付稳定文件快照后运行 `npm test`、`npm run build`；开发期间不与主控争用构建输出。
- 本轮浏览器由主控操作，QA 审查其明确交付的操作记录和截图。证据来源写为“主控浏览器实测／QA 审查”，不写成 QA 亲自执行。

## 报告与放行口径

每次交接记录受测提交或文件快照、命令结果、视口与 URL、具体操作及证据来源。对主控测试材料只审查实际覆盖的条目；截图只能证明可见布局，不能单独证明暂停、撤销或存档逻辑。

阻止合入的问题包括无法进入／完成／重试单局、命中偏移、界面穿透改图、暂停仍推进、资源或存档损坏、核心入口不可达、结果不一致和构建失败。轻微视觉差异记录复现条件及后续安排，不将未验证条目写成通过。

自动检查通过与浏览器流程通过分别记录；“更好看”“更易理解”“愿意重试”仍需用户或真实玩家评价。真实触屏、设备性能和声音听感尚未验收。
