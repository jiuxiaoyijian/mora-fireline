# 设计决策

截至 2026-09-17，当前方向为单关建造与山火演练。原题解读和备选路线见 [历史需求](archive/01-题目解读与落地方案.md)，完整决策链见 [归档](archive/02-设计决策记录.md)。

| 决策 | 目的与代价 |
| --- | --- |
| 保留建造—演练—观察—修改循环 | 让布局变化可比较；不扩展为城市经济或实时救援 |
| 固定 12 栋住宅、12 点预算 | 避免少建房屋规避损失；搬迁住宅不收费 |
| 确定性模拟、0.1 秒固定步进 | 同布局可复现；表现帧率与规则分离，无随机灾害 |
| 草地可燃、喷淋共享降温能力 | 拆除不等于免费隔离；覆盖多个目标会分摊效果，不能扑灭已燃建筑 |
| 六边形与天然岩带分区 | 六邻接统一表现和规则；两片住宅区使局部改善可见，但不能据此宣称平衡完成 |
| 45 秒演练，全毁后自动完成剩余计算 | 缩短无意义等待；跳过演出不截断模拟结果 |
| 防灾规划员身份、8/12 户委托 | 建立行动目标，解释重复尝试；代入感尚待真人验证 |
| 温暖低多边形场景、木框纸面 UI | 当前 dev.4 已替换深蓝金界面；可调透视镜头，HUD 随窗口重排 |
| 程序化远景与统一河海水面 | 控制资产依赖；沙岸和碎浪提升融合，但水景不参与消防规则 |
| 增量建造、远景合批、缓存阴影 | 降低渲染负担；退出演练仍需重建场景，低端设备待测 |
| 公开仓库 + GitHub Pages | 用户已授权分享，main 经检查后自动部署 |

当前不做多灾害、真实流体/刚体、经济系统、账号、联机、排行榜或多关成长。新增内容先验证是否改善现有单关体验。

2026-09-17 输入优化：沿已记录的屏幕指针路径采样后拾取六边形，避免直接以起终点在地图上连捷径；同笔划去重，保留逐格预算与撤销。右键专用于镜头，Esc／按钮取消搬迁，避免浏览器 contextmenu 触发时序造成冲突。取消操作终止后续输入，已成功铺设部分仍保留并可撤销。该实现位于独立分支，尚未发布。
