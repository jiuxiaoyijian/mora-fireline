# 设计决策记录

此处整理可分享的设计依据、备选方案、取舍和验证计划，帮助评审了解关键判断。记录的是结论与依据摘要，不是完整逐字思维记录。状态区分「工作假设」「已采用」「已验证」。

## D001：先聚焦建造与火灾模拟

- 日期：2026-09-14。
- 状态：工作方案；用户在后续请求中要求按当前方案继续整理、建仓，再细化规则和实现。
- 问题：在三个开放方向里，怎样以有限范围展示系统策划能力？
- 判断：火势传播让玩家选择与结果之间的关系容易观察，可通过重放同一灾害展示布局优化。
- 备选：异常观察更易收缩；肉鸽需要同时处理战斗、成长与数值。
- 代价：需要额外解释因果，防止玩法退化为看动画。
- 验证：观察首次玩家能否说清损失原因、是否愿意修改布局重试。

## D002：固定时间步的规则模拟

- 日期：2026-09-14。
- 状态：技术方案，待实现。
- 判断：用热量、邻接传播、风向和消防降温表达灾害；渲染只负责呈现结果。
- 备选：真实刚体破坏可增强视觉，但增加成本且难以解释和复现。
- 验证：同布局多次运行结果完全相同；不同画面帧率不改变规则结果。

## D003：重试保留布局

- 日期：2026-09-14。
- 状态：产品方案，待实现。
- 判断：保留布局、恢复状态，减少无意义重复操作，方便实验。
- 风险：需要保证计时器、火焰、事件和结果全部重置。
- 验证：至少连续运行、重试三轮，验证结果和状态。

## D004：固定住宅数量，限制防灾预算

- 日期：2026-09-14。
- 状态：规则假设，待细化。
- 判断：住宅数量固定，避免少建住宅获得虚假的高幸存率；限制防灾投入形成取舍。
- 风险：若地图太空、隔离免费，散开放置可能解决全部问题；若消防太强，可能只有一种策略。
- 验证：比较聚集、隔离、消防覆盖等不同布局；至少找到两种可达标方案，并审查明显的无成本解。
