# 当前游戏规则

核对：2026-09-17，包版本 `0.2.0-dev.4`。数值来源：[model.ts](../src/sim/model.ts)。

## 目标与地图

玩家是松风镇防灾规划员。居民已撤离，目标是在一次 45 秒演练中保住至少 8/12 栋住宅；12 栋全部保住为完整守护。演练不会永久烧毁保存的布局。

地图为 8×8 错行六边形、六邻接。B–G 列第 2、3、5、6、7 行共 30 格可建造，第 4 行为不可修改的天然岩带。西侧 A3、A6 为固定火源，干草带允许绕行。默认住宅在 D2–F3、D5–F6，两片各 6 栋。

## 资源与设施

开始前必须安置齐 12 栋住宅，防灾预算为 12 点。建造期间可替换、拆除和搬迁，拆除设施返还预算；运行或暂停时不能改建。

| 地块 | 作用与限制 |
| --- | --- |
| 住宅 | 免费、可搬迁；需要保护，可受热燃烧 |
| 草地 | 可燃，拆除后恢复草地，不能当防火带 |
| 防火带 | 1 点/格，不燃不传火，只阻断经过该格的传播 |
| 蓄水喷淋 | 4 点/座，本体不燃；六边形距离 2 步内共享每秒 72 降温能力 |
| 岩地 / 火源 | 固定，不可建造、拆除或搬迁 |

喷淋只给范围内未燃烧、正在受热或已有热量的可燃地块分配降温。不能恢复住宅生命，也不能扑灭已起火建筑。覆盖提示不等于最终保住，水青反馈表示实际分配量。

## 模拟与结算

固定步长 0.1 秒，共 450 步；同布局同规则结果一致。火只向共边邻居传播：正东热输入 22、正西 6、四个斜向 12。草地/住宅点燃阈值分别为 24/50，自然降温为每秒 2；其余参数以代码为准。

住宅在结束时既未烧毁也未燃烧才算保住。全部住宅烧毁后自动计算剩余步骤并结算；「查看结果」也执行完整剩余模拟。默认布局在 19.2 秒全毁；部分保护和全保护仍正常播放。复盘的起火来源是点燃当步最大单格热输入，不是完整因果链。

流程：标题 → 建造 → 2.4 秒预警 → 演练/暂停 → 结算 → 保留布局调整。帮助、菜单或失焦会暂停，2× 只改变播放速度。重试重置热量、燃烧和事件。

## 操作与保存

- 1–4 切换工具，点击建造；防火带可拖动连续铺设，逐格计费和撤销。
- 住宅工具先选房屋，再点空草地搬迁；Esc 可取消。Ctrl/Cmd+Z 撤销，最多 40 步。
- 空格开始/暂停；Esc 关闭最上层弹层、取消搬迁或打开菜单。恢复默认、新规划与清空需确认。
- 滚轮缩放，右键拖动环视和俯仰，也有镜头按钮。默认隐藏格线，覆盖和传播路径可按需开启。
- 地图辅助与镜头按需展开；触屏可用镜头按钮，尚未实现双指缩放。横竖屏 HUD 自动重排，真实手机仍待验收。
- 点击目标纸签查看委托；复盘点击事件高亮住宅，宽屏地图与列表并排。
- 菜单集中声音、标准/流畅画质、全屏及帮助，重新规划区包含默认布局/清空。声音默认关闭；画质、镜头及装饰不改变规则。

布局使用 localStorage 键 `fireline-layout-hex-v2`，旧方格存档保留但不转换。刷新只恢复布局，不恢复运行进度、成绩比较或撤销历史；本地与线上存档不互通。

雪山、河海、场外树林和门前小路都是装饰，不阻挡或传播规则内火势。
