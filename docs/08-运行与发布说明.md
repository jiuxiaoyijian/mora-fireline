## 开发与回归

使用 `.nvmrc` 指定的 Node 版本，执行 `npm ci`，然后 `npm run dev`。提交前执行 `npm run check`，包含规则、性能结构、CPU 基准、类型检查和生产构建。`npm run preview` 用于验收生成的 dist。

## 自动发布

main 分支更新后，Actions 安装锁定依赖并运行完整检查；成功后上传 dist，由 deploy-pages 发布。也可以手动触发 workflow_dispatch。仅文档更新可在提交消息使用 `[skip ci]`，不重新构建游戏。旧 `docs/deployment/pages.yml` 仅为历史模板，以实际工作流为准。

游戏在浏览器中执行，无后端或密钥。Vite 相对资源路径适配仓库子目录。模型由代码生成，依赖随构建打包。布局保存在当前浏览器当前来源的 localStorage 中，本地存档不会自动同步到线上。

## 发布验收

每次发布需检查 Actions 成功与页面加载、资源请求、演练结算、调整布局和刷新恢复。桌面横屏为主要目标；实际手机、低端设备性能和真人体验仍待验证。自动检查不代替真人试玩。
