# 运行与发布

**[在线游玩](https://jiuxiaoyijian.github.io/mora-fireline/)** · [公开仓库](https://github.com/jiuxiaoyijian/mora-fireline) · [Actions](https://github.com/jiuxiaoyijian/mora-fireline/actions)

截至 2026-09-17，Pages 已部署水景融合版本（3827420）。

## 本地命令

使用 [.nvmrc](../.nvmrc) 指定的 Node 24.13.1，执行 `npm ci` 安装锁定依赖。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | Vite 本地开发 |
| `npm test` | 26 项规则/六边形/播放检查 |
| `npm run test:perf` | 5 项性能结构检查 + CPU 基准 |
| `npm run check` | 上述测试 + 类型检查 + 生产构建 |
| `npm run preview` | 预览已构建的 dist |

## 发布

[实际工作流](../.github/workflows/pages.yml) 在 main 推送或手动触发时执行：安装依赖 → 完整检查 → 上传 dist → 部署 Pages。纯文档提交可使用 `[skip ci]` 跳过游戏构建。历史模板已归档，不用于发布。

网站为纯静态应用，无后端/密钥；Vite 相对资源路径适配仓库子目录，运行依赖随构建打包。布局只保存在当前来源的浏览器 localStorage，本地和线上不互通。

发布后核对 Actions 成功、线上新资源、进入/演练/结算/修改、刷新恢复及浏览器错误。桌面横屏为主要目标，真机移动端仍待验收。Three.js 分包约 555 kB（gzip 138 kB），构建有体积提示但成功。
