# 工程结构与接续分析

基线：`fc094c9`（v0.2.0-dev.2）。这是一款可静态部署的单关 3D 建造与防灾原型，已经具备完整交互循环，尚未完成玩法平衡与真人体验验收。

后续更新：本文保留改造前结构与判断；最新六边形实现、测量和剩余项见 [六边形山谷与镜头迭代](20-六边形山谷与镜头迭代.md)，当前排期仍以 14 为准。

## 内容与代码分层

| 位置 | 职责 | 接续注意点 |
| --- | --- | --- |
| `src/sim/model.ts` | 8×8 地图、布局校验、预算、450 个固定规则步、火势与降温、事件和结果 | 与渲染独立；修改规则必须更新测试、存档兼容与当前规则说明 |
| `src/sim/playback.ts` | 本轮新增：完整推进、全毁后停止演出 | 不改传播规则，不删事件，不将短暂平静判为安全 |
| `src/sim/*.test.ts` | Node 内置测试，17 项模型检查 + 5 项播放检查 | 确定性与合法性证据，不代表趣味性 |
| `src/main.ts` | 准备／预警／运行／暂停／结算状态，编辑撤销、存档、HUD、复盘 | 当前主要耦合点；未来按流程与存档边界逐步拆分，避免无目标重构 |
| `src/view.ts` | Three.js 场景、程序建筑、拾取、覆盖和火灾表现 | 只消费规则状态；新增表现不能隐含改变机制 |
| `src/ui/`、`src/style.css` | 模板、1920×1080 舞台缩放、弹层焦点和样式 | 保持固定画幅和子路径可用性；长结算文本需视觉检查 |
| `src/audio.ts` | 用户主动开启的 Web Audio 合成音 | 声音听感仍待真人确认 |
| `scripts/triage-probes.ts` | 默认住宅下设施方案的定向测量 | 不是全部搬迁、混合方案空间的穷举；旧证据是 v0.1 地图基线 |
| `docs/` | 题目、设计、规则、排期、QA、证据和部署模板 | 14 是进度入口；历史记录保留，新增结论按批次追加 |

技术栈为 TypeScript、Three.js、Vite，无后端、账号或远端存档。布局存于浏览器，撤销和结果比较仅限当前会话；刷新不会恢复模拟进程。

## 当前实际完成度

- 已贯通：标题进入 → 建造／搬迁／撤销 → 预警 → 暂停／加速／查看结果 → 家园结算／传播线索 → 保留布局重试。
- 已具备：木石小镇风格、实际降温反馈、可选声音、游戏内弹层、静态资源相对路径。
- 玩法主要缺口：当前西侧六格防线形成明显低成本满保方案，缺口造成近乎全灭；局部建造收益与设施取舍仍需 S2 验证。
- 工程主要缺口：流程代码集中于 main；浏览器检查目前以实际操作记录为主，尚无仓库内完整自动化 UI 回归套件。
- 验收主要缺口：首次玩家行为、真实移动设备、低端性能和正式公网发布均未完成。

## 本轮开发选择

先完成 A05.2 的确定性全毁收束。默认局最后一栋住宅在 19.6 秒烧毁，此后不可能恢复住宅，但旧版本继续播放至 45 秒。现在由独立播放层在每个固定步后检查全毁，推进剩余步骤，再显示结算；保留完整事件并明确告知自动跳过的原因。

没有选择“几秒没有新起火就结算”：火源持续燃烧，热量仍可积累，静默不是稳定性的证明。也没有截断模拟，因为那会改变草地终态和后续传播记录。保护成功的布局仍可正常观察全部 45 秒，或主动查看结果。

## 后续顺序

1. **A06.1：分区测量先行。** 在候选地图上验证至少三档保护数量，其中包含部分保护和达标；至少两种有差异的达标方案。验证隔离缺口、喷淋、混合设施及最低成本明显解，之后再替换正式地图。
2. **同步处理地图升级。** 固定地形、可建造性、浏览器旧布局校验、图面提示与参考布局要一起更新，不能只改住宅排列。
3. **A03／A06.2：起局和解释。** 用实际模型数据表现局部挡火和喷淋负载；有希望的初始布局应有测量依据。
4. **Q02：真人体验。** 邀请首次玩家观察是否理解失败、能否主动做出一次有效改动；技术 QA 不替代此项。

本轮交付是一个明确的小迭代，不将其计作 S2 分区或完整 v0.2 完成。验证结果见开发日志。
