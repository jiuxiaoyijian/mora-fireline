# 固定画幅与游戏内交互设计

日期：2026-09-16。用户要求从网页布局转为固定设计分辨率的游戏体验，将摆放、开始、返回主菜单等交互放在游戏内。

## 画面原则

- 设计基准为 1920×1080，舞台按窗口宽高中的较小缩放比例适配。非 16:9 窗口留边，保持场景与 UI 比例，不通过页面滚动寻找操作。
- 固定的是布局坐标，不强迫显示器使用 1920×1080；WebGL 按显示尺寸与设备像素比调整渲染密度。
- 三维地图作为全画幅背景，顶部放目标、住宅、预算与系统菜单，底部放建造工具与模拟控制。地图完整取景避开主要 HUD。
- 主菜单、帮助、暂停和结算位于同一游戏舞台，随画面一起缩放。只有复盘等长内容允许弹层内部滚动。
- 本轮以桌面横屏为主要目标；竖屏仍等比完整展示，但不宣称已达到手机触控可用性。

## 操作约定

| 场景 | 操作 | 结果与保护 |
| --- | --- | --- |
| 主菜单 | 开始游戏／继续建设 | 进入准备阶段；存在本次暂停进程时保留进程，继续按钮恢复到可继续的暂停画面 |
| 主菜单 | 重新规划 | 确认后恢复默认街区，清除本会话成绩和撤销历史；取消不改变布局 |
| 建造 | 选择底部工具，再点击地图 | 合法性、费用和喷淋范围预览；成功后更新资源与存档，非法操作不扣费 |
| 搬迁 | 住宅工具点现有房屋，再点空草地 | 保持住宅数量；再次点原屋、Esc、右键或取消按钮取消 |
| 建造 | 撤销／Ctrl 或 Cmd+Z | 恢复上一步布局与资源，沿用最多 40 步会话历史 |
| 建造 | 默认街区／清空重建 | 先确认；布局操作可撤销，成绩清除不可通过布局撤销恢复 |
| 准备完成 | 准备好了 | 住宅齐全才可开始，进入 2.4 秒预警，再执行原有 45 秒模拟 |
| 运行 | 暂停／继续、加速、查看结果 | 按原固定步长执行；查看结果完成剩余模拟再结算 |
| 任意局内阶段 | 菜单按钮／Esc（非搬迁时） | 打开游戏菜单，运行与预警自动暂停 |
| 游戏菜单 | 返回主菜单 | 保留当前布局与本次会话状态；回到游戏后可继续 |
| 游戏菜单 | 返回建造 | 确认放弃本次火情进度后回到建造，保留布局，不伪造成绩 |
| 结算 | 改善防线／查看复盘 | 修改保留布局；复盘在游戏内显示，含原样重试；关闭后可再次查看成果 |
| 辅助操作 | 帮助／键盘网格 | 弹层打开时屏蔽底层交互；网格支持数字选工具、Tab 选格、Enter 建造 |
| 显示 | 全屏 | 尝试浏览器全屏；不支持时提示并保持窗口模式可玩 |

Esc 优先关闭最上层弹层；主菜单不会被 Esc 跳过。关闭帮助或菜单不隐式推进火情，继续通过明确按钮执行。失焦自动暂停沿用原规则。

## 实现与协作边界

UI Agent 负责模板与样式；主控负责舞台缩放、弹层栈、流程绑定、相机与拾取适配；美术 Agent 提供只读取景与像素密度评审；测试 Agent 准备回归矩阵并执行独立命令检查。

模板与图标抽到 `src/ui/template.ts`；舞台适配和弹层管理分别位于 `src/ui/stage.ts`、`src/ui/dialogs.ts`。模拟规则保持在原模块，不因改 UI 复制或改写判定。模态层显式管理焦点与 inert，避免浏览器顶层弹窗脱离舞台缩放。

## 验证与范围

验收记录统一见 [固定画幅交互回归](../qa/固定画幅交互回归.md)。检查比例与留边、缩放后的点击位置、HUD 遮挡、菜单与暂停、确认取消、完整结算和重试、刷新存档及静态子路径。

地图、资源价格、火势算法和胜负条件本轮不变。分区、渐进收益和设施取舍仍是后续规则工作，不因游戏界面改造而标成完成。美术模型仍为现有程序模型，没有新增外部资源。
