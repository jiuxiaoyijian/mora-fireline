## 接续步骤

1. 查看 `git status`，保留本地工作；工作区适合更新时再执行 `git pull --ff-only`。
2. 使用 [.nvmrc](../.nvmrc) 对应 Node，`npm ci`，修改前确认当前复现条件。
3. 规则/渲染改动运行 `npm run check`，可玩变化再做浏览器 QA；文档变化检查链接与事实即可。
4. 更新对应现行文档和简短开发记录；提交前核对差异。main 推送会自动发布，发布后核对 Actions 与线上资源。

跨设备只同步代码与文档，聊天和浏览器布局不随 Git 同步。多 Agent 文件仅保留历史方案，不要求每轮启动多个 Agent。
