## 本批选择与改动

优先修新增输入的可复现代码风险，不同时改数值或替换美术：旧实现跨格会重复调用上一格，稀疏移动事件可能漏格；指针没有完整按 ID 隔离，右键镜头共用 contextmenu 取消搬迁。

抽离 `src/input/gesture.ts`：累计 5 CSS 像素移动阈值；绘制、普通点选和镜头手势分离；沿每一段实际屏幕路径以最多 8 像素间隔采样，再由场景拾取地块。同笔划去重，松手补最后一段。普通工具大幅拖动不落子，避免误搬迁／误建造。

主控接入：岩带与场外格不建，DOM 命中确认过滤 HUD 覆盖；只有主指针控制当前手势。切工具、开弹层、开始演练、Esc、失焦或捕获丢失终止笔划。右键只负责镜头；搬迁通过 Esc／取消按钮结束。取消不会回滚已经铺设的格子，仍可逐格撤销。

测试 Agent 独立补 8 项输入测试并加入 npm test；主控负责代码集成和浏览器实测。火势、预算、设施成本、住宅数与渲染风格不变。
