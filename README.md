## 游戏定位

- 目标体验：第一次观察损失，第二次通过修改布局保住更多住宅，并理解原因。
- 形式：低多边形 3D 沙盘，斜俯视镜头，鼠标建造。
- 单次模拟目标：约 45–60 秒；整个体验约 3–5 分钟。
- 技术计划：TypeScript、Three.js、Vite；纯浏览器运行，GitHub Pages 部署。
- 核心循环：建设 → 实验 → 观察 → 调整 → 再次实验。
