# 火线街区 · Fireline

**[在线游玩](https://jiuxiaoyijian.github.io/mora-fireline/)** · [GitHub](https://github.com/jiuxiaoyijian/mora-fireline) · [文档目录](docs/README.md)

你是松风镇的防灾规划员。居民已撤离，用 12 点预算规划防线，通过反复演练保住至少 8 户，争取守住全部 12 户。

这是面向 Mora 游戏策划 Vibe Coding 测试的单关 3D 浏览器原型，使用 TypeScript、Three.js、Vite，由用户与 Codex 协作开发。当前包版本为 `0.2.0-dev.4`；仓库已公开，GitHub Pages 已上线。

## 怎么玩

1. 选择防火带（1 点/格）或蓄水喷淋（4 点/座），点击地图建造；防火带支持拖动铺设，住宅可搬迁。
2. 安置齐 12 栋住宅后点击「开始演练」，观察 45 秒山火；可暂停、2× 加速或跳到结果。
3. 查看损失与起火线索，保留布局修改，再次验证。

滚轮缩放，右键拖动调整镜头；1–4 切换工具，空格开始/暂停，Ctrl/Cmd+Z 撤销。菜单提供流畅画质。布局自动保存在当前浏览器；刷新不保留火情和成绩。

## 本地开发

使用 Node.js 24.13.1（见 [.nvmrc](.nvmrc)）：

~~~sh
npm ci
npm run dev
npm run check    # 规则、性能回归、类型检查和生产构建
npm run preview  # 预览 dist
~~~

main 更新后由 [GitHub Actions](.github/workflows/pages.yml) 自动检查并部署。

## 当前状态与边界

已实现六边形地图、建造—演练—复盘循环、可调透视镜头、巡护站 UI，以及雪山、河流和海岸。水景仅作装饰，不参与火灾判定。

已替换为浅木框与纸面 UI：任务签、阶段工具栏、按需展开的镜头/图层、可定位地块的复盘；HUD 按窗口重排，不再整体缩小。设计依据与实施边界见 [UI 风格与交互层级](docs/11-UI风格与交互层级.md)。

本地输入优化版已通过 39 项自动检查及定向桌面浏览器验收：拖动防火带沿指针路径补采样，同一笔划每格只处理一次；右键镜头不再取消搬迁。此修改在 `codex/drag-input-polish` 分支，尚未合入或发布。

尚无真人试玩或真实手机、低端设备验收。当前只有一个固定场景，防火带低成本解较明显，设施平衡与身份代入仍需验证。前版浏览器样本约 32 FPS，本轮没有重新测量 FPS，不能宣称卡顿已彻底解决。
