# 火线街区 · Fireline

**[在线游玩](https://jiuxiaoyijian.github.io/mora-fireline/)** · [GitHub](https://github.com/jiuxiaoyijian/mora-fireline) · [文档目录](docs/README.md)

你是松风镇的防灾规划员。居民已撤离，房屋不可移动；用防火带隔断地面火，用喷淋降温并拦截飞火，在八次渐进委托中守住家园。

这是面向 Mora 游戏策划 Vibe Coding 测试的 3D 浏览器关卡原型，使用 TypeScript、Three.js、Vite，由用户与 Codex 协作开发。仓库已公开，通过 GitHub Actions 检查并部署至 GitHub Pages。本轮包含性能与喷淋平衡、屋顶湿润/飞火反馈，以及终章分享与重开流程。

## 怎么玩

1. 从第一关学习防火带、绕行和喷淋；随后挑战飞火、木砖房屋、转向风和紧缺预算。
2. 观察本关目标与天气，点击/拖动布置防护，再开始 20–45 秒演练；可暂停、2× 加速或查看完整结果。
3. 根据预热、飞火落点与复盘修订防线。通关解锁下一关，全保并达到节约目标可获三星。

1 查看、2 防火带、3 喷淋、4 拆除；空格开始/暂停，Ctrl/Cmd+Z 撤销。滚轮缩放、右键环视，菜单可切换流畅画质。每关防线、解锁与最好星级保存在当前浏览器，刷新不恢复火情；新规则保留旧解锁进度，防线与星级独立记录，旧存档保留。

## 本地开发

使用 Node.js 24.13.1（见 [.nvmrc](.nvmrc)）：

~~~sh
npm ci
npm run dev
npm run check    # 规则、性能回归、类型检查和生产构建
npm run preview  # 预览 dist
~~~

main 更新后由 [GitHub Actions](.github/workflows/pages.yml) 自动检查并部署。

准备阶段不再常驻显示底部图例；火情反馈在演练中出现。

## 当前状态与边界

喷淋改为相邻一圈、每秒共享 48 降温量；每座共享 2 次飞火拦截储备，每 4 秒补 1 次。后期阵风可从不同燃烧地块卷起多枚飞火，隔离草地跳板能减轻喷淋压力。八关地图、预算与三星目标已重校，固定房屋与风向预报保留。规则仍与渲染分离；雪山与河海仅作装饰。

性能优化包括岩地/建筑装饰合批、镜头不再重复重置画布、同格预览复用、重试复原模型而不整体重建。同布局浏览器样本：绘制调用 296→84，CPU P95 5.1→2.5ms；内置浏览器仍约 32 FPS，不代表真机卡顿已完全解决。

自动检查覆盖每关无防护失败与可行解、固定房屋、飞火/湿润、风向时序、重试确定性、存档及性能。AI 浏览器已走通 8 关、失败后修改重试及桌面/横竖屏检查。**没有真人试玩或真机验收**；难度曲线、后期设施取舍仍需玩家反馈，Node 性能基准不能代替真实设备 FPS。
