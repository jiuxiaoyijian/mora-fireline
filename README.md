## 游戏定位

- 目标体验：第一次观察损失，第二次通过修改布局保住更多住宅，并理解原因。
- 形式：低多边形 3D 沙盘，斜俯视镜头，鼠标建造。
- 单次模拟：45 秒，可 2× 加速；完整体验目标约 3–5 分钟，仍需真人试玩验证。
- 技术：TypeScript、Three.js、Vite；纯浏览器运行，已按 GitHub Pages 子路径验证静态构建。
- 核心循环：建设 → 实验 → 观察 → 调整 → 再次实验。

## 怎么玩

1. 直接点击「启动火灾」，观察默认街区的损失。
2. 结算后查看传播来源，选择「调整布局」。
3. 用 12 点预算布置防火带（1 点 / 格）或消防站（4 点 / 座）；始终需要安置 12 栋住宅。
4. 再次启动同一场火灾，保住至少 8 栋即达标。

点击地图建造；1–4 切换工具；空格开始 / 暂停。地图下方也提供键盘操作网格。消防站负责邻近降温，无法救回已燃烧的住宅。空地仍有可燃植被，不能代替防火带。

布局自动保存在当前浏览器，Git 同步的是代码与文档。重试保留布局，结果对比仅保留在本次页面会话中。
